# 📚 Meus Estudos: HTML5 e CSS3 (Curso em Vídeo)

Este repositório foi criado para organizar todos os exercícios, desafios e projetos práticos que venho desenvolvendo durante o curso de **HTML5 e CSS3**, ministrado pelo professor Gustavo Guanabara no [Curso em Vídeo](https://www.cursoemvideo.com).

---

## 📖 O que estou aprendendo?

O curso é focado em transformar um iniciante em um desenvolvedor Front-End capaz de criar sites modernos e responsivos.

### Principais tópicos:
* Semântica em HTML5.
* Estilização avançada com CSS3.
* Design Responsivo (Mobile-first).
* Tipografia e harmonia de cores.

---

## 🛠️ Ferramentas Utilizadas
* **Editor:** Visual Studio Code.
* **Versionamento:** Git e GitHub.
* **Design:** Chrome DevTools para testes.
